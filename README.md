# AI 星际舰队 · Scratch 图形化编程一级课程

面向三年级、一对一授课的 GESP 图形化编程一级备考课程，用「星际舰队闯关」剧情串起 12 节课，并在每节课加入 AI 前沿体验。

## 课程结构

- 12 节课 = 12 颗星球，覆盖 GESP 一级全部 8 个知识块、15 条考纲条目
- 每节课 80 分钟，分四个环节：
  1. AI 小剧场（10 分钟）：AI 前沿新闻、知识胶囊、动手体验、小问答
  2. 核心考点（25 分钟）：本课知识点 + 考试陷阱
  3. 闯关项目（30 分钟）：可打勾的任务清单 + Scratch 积木参考程序
  4. 考场演练（15 分钟）：3 道单选 + 2 道判断（逐题即时判分）+ 1 道编程小题
- 第 12 课为考前攻略、限时模拟与结营
- 一套全真模拟卷（单选 10、判断 5、编程 2，满分 100）
- 舰队手册：网站用法、需要的装备、打不开时的替代方案、AI 安全公约

## 文件

| 文件 | 内容 |
|---|---|
| `ai-star-fleet/index.html` | 课程网站（星图、课程页、模拟考、舰队手册） |
| `ai-star-fleet/lessons-a.js` | 第 1–6 课内容 |
| `ai-star-fleet/lessons-b.js` | 第 7–12 课内容与模拟卷 |

课程内容都放在两个 `lessons-*.js` 数据文件里，修改题目或文案只需要改这两个文件。

## 本地打开

页面会加载同目录下的数据文件，所以需要用本地服务器打开，不能直接双击 HTML：

```bash
python3 -m http.server 8765 --directory ai-star-fleet
```

然后在浏览器访问 http://localhost:8765 。
